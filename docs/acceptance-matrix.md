本文件由主代理依据已冻结需求建立，作为代码返回后的审查依据。这里列的是待验证标准，不能据此声称已经通过。

## 规则的独立组合计数

2026-09-25使用独立Python枚举核对：每个骰子取1–6，共`6^6=46656`种有序组合，按房规优先级得到下列精确数量。开发实现应与此逐项一致，比仅验证“总数正确”更能发现优先级错误。

| 代码 | 有序组合数 |
| --- | ---: |
| chajinhua | 15 |
| liuhong | 1 |
| biandijin | 1 |
| liuhe | 4 |
| wuhong | 30 |
| wuzi | 150 |
| sihong | 360 |
| duitang | 720 |
| sanhong | 2500 |
| sijin | 1875 |
| erju | 9300 |
| yixiu | 17400 |
| none | 14300 |
| 合计 | 46656 |

这只是理论分布，不是对实际RNG公平性的统计证明；生产随机数还需检查确实使用`crypto.randomInt`。
