## 2. 一致的基础玩法

每人轮流向碗中投六颗六面骰子，按点数组合判奖。其中“四点”为判定红点数量的依据。骰面一点和四点通常画为红色，但“一点”不能计入一秀、二举、三红中的四点数量。

| 奖项 | 通常的基础条件 | 传统每会数量 |
| --- | --- | ---: |
| 状元 | 四个四点、五个相同点数等状元牌型 | 1 |
| 对堂 | 1、2、3、4、5、6各一个 | 2 |
| 三红 | 三个四点 | 4 |
| 四进 | 四个相同点数，点数不是四 | 8 |
| 二举 | 两个四点 | 16 |
| 一秀 | 一个四点 | 32 |

数量合计63。具体判定必须先排除更高牌型，例如1–6各一个只判对堂，不再判一秀。

## 3. 存在分歧的部分

- 百科资料将六红、全黑列在插金花之上；本地宝将插金花列为最高，并把六个一点称为遍地锦。
- 五子登科存在“先比另一颗”与“先比五颗相同的点数”的差异。
- 插金花是否同时获得两个对堂、六红是否拿走全部奖品、普通奖是否追缴、四进是否兼得一秀/二举，均需要开局约定。
- 线下“掉出碗外无效”“关灯抢饼”不适合直接搬到网页；随机动画也不应决定投掷是否有效。

## 4. 本项目冻结的「线上统一房规 v1」

采用常见牌型名称，明确以本房规为准。页面必须说明“特殊牌型各地有差异，本房间采用线上统一房规 v1”。以下是产品约定，不包装为唯一传统规则。

### 4.1 判定顺序和状元比较

从上到下匹配且只匹配一项。`rankKey`从左到右比较，较大胜；相同则保留先博得者。点数顺序不影响结果。

### 4.2 奖池和结算

- 初始普通奖池：对堂2、三红4、四进8、二举16、一秀32；状元1单独保留。
- 普通奖中奖且库存大于0时减1；库存为0时显示“博得X，奖品已领完”，不降级、不补发、不追缴。
- 一次投掷只判最高牌型；四进带四点不兼得一秀/二举；插金花不额外领对堂；六红不清空奖池。
- 状元候选通过`rankKey`竞争。每人保留自己的最佳状元成绩，房间保留当前领先者；超过当前领先者才替换；同分先到先得。
- 状元奖在整局结束时发给领先者。没人掷出状元则显示“本局状元空缺”，状元库存保留1。
- 展示各玩家获奖总数和六档明细，不引入积分或金钱。战绩列表按状元拥有者优先、普通奖总数降序、入座顺序升序排列；这个列表不冒称传统积分规则。

### 4.3 线上轮次和结束条件

- 创建时每人轮数从5/10/20选择，默认10；2–12人，默认人数上限8。
- 服务端在开局时随机选起始玩家，之后按入座顺序循环。开局后不加入新玩家。
- 每次机会30秒；超时记“超时跳过”，不掷骰、不发奖，并消耗一次机会。
- 达到轮数上限后结算。五类普通奖全领完时，完成当前整轮后结算；该轮尚未轮到的玩家仍可争夺状元。
- 房主可以确认后提前结束，保留已发奖品并结算状元，页面显示“房主提前结束”。
- 对局中明确离开的席位保留历史，后续跳过且不重排席位；在座玩家少于2人则提前结算，原因为“参与人数不足”。
- 全员掉线时暂停倒计时；有人重连后恢复剩余时间。刷新不丢身份，不重新掷骰。
- 传统的“所有饼领完再额外打一轮”与本版“完成当前轮”不同，规则面板必须写清。
