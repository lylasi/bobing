## M01 手机对局骰碗始终不可见（阻断）

- 证据：主代理亲自查看 `docs/screenshots/12-playing-375.png`，只有房间栏、轮次、玩家 Tab 和列表、固定掷骰按钮，没有骰碗或结果。
- 根因：`src/styles.css` 移动断点中的 `.game-panel { display:none }` 作用于 `.game-panel--center`；中心区没有 `is-active`，也不属于三个 Tab，因此在任何 Tab 中都不可见。
- 原需求：`docs/ui-brief.md` 第2节第4条明确“手机优先显示轮次/当前玩家/碗/按钮，再以Tab切换玩家/奖池/记录”。
- 实现要求：375/768 对局中心始终渲染并可见，轮次下先显示骰碗、当前提示、最新结果，再显示辅助信息 Tab 与当前面板；底部仅一个主掷骰按钮且不遮挡可滚动内容。1440 保留280/560/312三栏。不要只把中心放到玩家列表下面，12人时主玩法不应被淹没。
- 回归要求：真实双上下文对局，375px 下 `.game-center`、`.bowl`、六个 `.dice` 必须可见，掷骰完成后可见点数匹配权威最新记录；切换玩家/奖池/记录时骰碗与结果仍可见；截图必须等待最新结果落定后生成，不能只截图空碗或记录标题。768 也要检查中心优先且不溢出。1440 既有列宽检查继续通过。
