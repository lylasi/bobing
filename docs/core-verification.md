真实重启并非只新建服务类：使用构建产物`dist-server/server/index.js`启动独立Node进程，临时SQLite目录，随机端口；通过HTTP创建2人5轮房间，两枚独立凭证和两个Socket真实连接；朋友准备、房主开始、当前玩家掷骰。随后SIGTERM关闭进程，重新启动另一个Node进程指向相同目录。

重启后验证：原房主凭证恢复原playerId；骰子/历史与奖池逐项一致；turnId不变；所有玩家先离线且房间暂停；两个原身份连接后恢复在线且解除暂停，不多一手骰子。断开并关闭临时进程后清理专用临时目录。

前端、响应式、实际分享弹层、生产整合启动和公网部署不在这份核心验收的通过范围。完整验收在后续`docs/verification.md`记录。
